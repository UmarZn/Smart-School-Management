# Smart School Management (SMKS19)

A simple educational quiz game developed using **Python** and **Pygame**.

## Features
- 📚 **Three quiz categories**
- 🎯 **Score system**
- ✅ **Automatic question progression**
- 🏆 **Quiz completion screen**
- 🔙 **Back button**
- ❌ **Exit button**
- 🎨 **Rounded modern interface**

## Technologies Used
- **Python**
- **Pygame**
